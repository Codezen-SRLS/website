# BeeZee Phase 2 security audit

BeeZee is a Cosmos SDK blockchain for simplified DeFi; this second-phase audit covered its Go burner, cointrunk, epochs and tokenfactory modules for token burning, on-chain raffles, curated content with tipping and token creation.

Codezen audited BeeZee Phase 2 together with Oak Security. Technologies in scope: Golang and Cosmos SDK. We reported 16 findings: 2 critical, 9 minor and 5 informational.

- Audit type: Cosmos SDK chain audit
- Technologies: Golang, Cosmos SDK
- Ecosystem: Cosmos
- Delivered with: Oak Security

# Divigent SDK and MCP security audit

Divigent is the treasury layer for x402 agent wallets on Base; this audit covered its MCP SDK for AI agents. Divigent provides adaptive reserves, just-in-time recall, venue monitoring and yield on idle USDC.

Codezen audited Divigent SDK and MCP together with Oak Security. Technologies in scope: AI and MCP. We reported 36 findings: 3 major, 21 minor and 12 informational.

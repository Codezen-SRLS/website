# Drop Updates 3 security audit

Drop Protocol is a liquid staking protocol on Neutron; this audit reviewed the third round of updates to its CosmWasm smart contracts in Rust, which use IBC, Interchain Accounts and Interchain Queries to stake across Cosmos.

Codezen audited Drop Updates 3 together with Oak Security. Technologies in scope: Rust and CosmWasm. We reported 12 findings: 1 major, 4 minor and 7 informational.

- Audit type: CosmWasm smart contract audit
- Technologies: Rust, CosmWasm
- Ecosystem: Cosmos
- Delivered with: Oak Security
- Report date: 20 March 2025

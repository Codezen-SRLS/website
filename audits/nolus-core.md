# Nolus Core security audit

Nolus Protocol is a DeFi suite; this audit covered the mint and tax Cosmos SDK modules of the Nolus chain, written in Go. Nolus offers money markets with a lease solution for leveraged positions with fixed borrowing costs.

Codezen audited Nolus Core together with Oak Security. Technologies in scope: Golang, Cosmos SDK and Nolus. We reported 11 findings: 1 major, 5 minor and 5 informational.

- Audit type: Cosmos SDK module audit
- Technologies: Golang, Cosmos SDK, Nolus
- Ecosystem: Cosmos
- Delivered with: Oak Security
- Report date: 12 December 2022

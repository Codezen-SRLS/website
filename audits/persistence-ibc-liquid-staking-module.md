# pSTAKE Native Auto-Compounding and Rebalancing security audit

Persistence's IBC liquid staking module is a Cosmos SDK module written in Go, audited here for pSTAKE native auto-compounding and rebalancing.

Codezen audited pSTAKE Native Auto-Compounding and Rebalancing together with Oak Security. Technologies in scope: Golang, Cosmos SDK, Persistence and Cosmos Hub. We reported 31 findings: 5 critical, 6 major, 10 minor and 10 informational.

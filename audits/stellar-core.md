# Stellar Core security audit

Audit of the Stellar Core.

Codezen audited Stellar Core together with Oak Security. Technologies in scope: C++, C, Soroban, Rust and Stellar. We reported 81 findings: 2 critical, 1 major, 35 minor and 43 informational.

# Thema Protocol security audit

Thema is a DeFi protocol for issuing asset-backed tokens (OMTs) minted and redeemed atomically against asset baskets; this audit covered its core Solidity contracts, with oracle-based NAV tracking and modular fee, oracle and token set interfaces.

Codezen audited Thema Protocol together with Oak Security. Technologies in scope: Solidity, Ethereum and EVM. We reported 26 findings: 1 critical, 10 major, 9 minor and 6 informational.

- Audit type: Solidity smart contract audit
- Technologies: Solidity, Ethereum, EVM
- Ecosystem: Ethereum
- Delivered with: Oak Security
- Report date: 27 December 2025
